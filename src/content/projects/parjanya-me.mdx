## Problem

I wanted one place for my projects, coursework and writing that would be easy to keep up to date. That pointed to something simple: plain static pages, free hosting, and content kept in ordinary files.

I also wanted it to feel a little like me, so it has a charcoal palette, one warm accent colour, and a few small animations.

## Approach

- **Mostly static.** Astro turns every page into plain HTML when the site is built. JavaScript only handles the interactive bits (the theme switch, page transitions, tabs and filters), and the intro's code only loads on the visit where it plays.
- **Content in files.** Projects, courses, books and posts are Markdown or YAML files with a schema, so a missing field shows up as a build error instead of a broken page.
- **The intro.** A small build script turns the letters of "parjanya." into SVG shapes, so the intro can show up before any fonts have loaded.
- **Page transitions.** Astro's client-side router swaps pages without a full reload, which leaves room for the shutter animation in between.

## Results

- It stays light: about 17 KB of compressed JavaScript for the whole site, and it does well in Lighthouse on both desktop and mobile.
- Everything still works with JavaScript turned off. The animations are layered on top.
- If your system asks for reduced motion, the intro becomes a short fade and page changes become a simple crossfade.

## Challenges

- **Timing the page transitions.** Getting the shutter to close while the next page loads, and to open only once that page is ready, took a few tries.
- **The zoom.** Working out how far to zoom so the whole screen ends up inside the letter took a bit of geometry. There's a separate [write-up](/writing/zooming-through-a-letter) on that.
- **Theme flashes.** Stopping the page from briefly flashing the wrong theme on load needed a tiny script that runs before anything is drawn.

## Limitations

- Browsers without SVG hit-testing get a rougher estimate for how far to zoom.
- The "ask" box is a keyword search over this site, not an AI, and it says so.
- Some of the content is still placeholder while I fill things in.
